# Attendance 视觉规范

本轮以 `master` 的 `fc2b278` 为基线。产品仍是完全离线、单机使用的班级事务工具；视觉设计以手机上的扫描、连续登记和快速复核为核心。

## 审查与改法

| 原实现 | 调整 |
| --- | --- |
| 主题仅提供动态色或 seed，未声明 Shape / Typography | 项目控制的默认配色、四种风格预设、统一形状和排版 |
| 点名整行叠加 24% 状态色，状态头像使用固定色配白图标 | 中性列表、小型 tonal 状态图标、轻分隔线；深浅色独立语义映射 |
| 材料完成项实心主色，学生和材料重复堆叠彩色块 | 学生级边框分组；材料为平坦行，业务绿色表示完成 |
| 草稿与材料历史整张 secondary / tertiary Container | 草稿细主色边框与“继续”；完成记录为安静的信息行 |
| 设置目的地、分组和页面简介重复彩色圆角块 | 页面标题、分组标题、平坦设置行与分隔线 |
| 班级选中态整张染色，当前标记依赖人数开关 | 小面积选中色、细边框、独立当前标记与管理按钮 |
| 页面分别声明 12–24dp 圆角 | 页面使用 MaterialTheme.shapes，圆形头像保留明确用途 |

## 三层颜色

1. **中性层**：背景、普通列表、学生分组、设置与完成历史。浅色主背景 `#F7F9FB`，surface `#FCFDFE`；深色主背景 `#11161B`，surface `#151B21`。outlineVariant 建立分组与行的边界，不使用阴影堆出层级。
2. **交互层**：Attendance 浅色主色 `#315A74`，深色主色 `#A8CDDF`。用于主要按钮、选中、进度和继续操作。动态或自定义配色仅替换强调色角色，中性表面及错误角色仍由项目控制。
3. **业务层**：默认到场为绿、迟到为赭黄、请假为蓝、缺勤为红、不参与与未登记为灰。材料完成为绿、不合格为红、未登记为灰。各颜色单独适配深色；用户选择的图标与颜色仍有效，显式选择“主题色”也保留。

业务颜色优先出现在图标和状态文字中。状态 badge / 头像 / 滑动揭示区使用不透明的浅 tonal fill：浅色 6%、深色 10%，与 surface 合成，避免滑动背景穿透前景。滑动触发距离、方向、回弹和回调不变。

## 风格与兼容

- **Attendance**：默认视觉语言。中性冷白 / 墨色背景、墨蓝交互、清晰紧凑的列表。
- **柔和**：同一业务语义与排版，浅色使用暖白背景，圆角与列表留白更宽松。深色保留清晰的文字对比。
- **系统动态**：Android 12+ 使用壁纸生成的强调色；更旧系统回退到 Attendance。形状、排版、状态和中性表面规则不变。
- **自定义**：一个 `#RRGGBB` 主色及少量快捷色。生成成对的前景/背景强调色，不新增背景、字体或组件圆角设置。

复用现有 `themeSource`（新增 `ATTENDANCE`、`SOFT` 枚举值）和 `themeSeed`。新安装和缺少主题字段的数据默认 Attendance；明确存储的 `SYSTEM`、`CUSTOM` 原样保留。主题仍仅属于全局，不参与班级覆写。旧数据与备份可由新版读取；包含新预设枚举的备份需要新版恢复，旧版不认识这些枚举值。未修改班级、学生、历史快照、草稿或材料数据结构。

## 形状与文字

| token | Attendance | 柔和 | 用途 |
| --- | --- | --- | --- |
| extraSmall | 4dp | 8dp | 紧凑状态标签 |
| small | 8dp | 12dp | 按钮、输入、平坦列表行与小型状态区 |
| medium | 12dp | 16dp | 学生材料分组、功能模块 |
| large | 16dp | 22dp | 较大的功能分组 |
| extraLarge | 24dp | 28dp | 对话框、底部面板 |

`AttendanceTypography` 显式定义全部 Material 文本层级，使用系统 SansSerif。页面标题 24–28sp，模块和学生姓名 16sp Medium，正文 14–16sp，学号、原因与辅助信息 12sp，状态标签 12sp Medium，统计数字 22sp Medium 且使用等宽数字特性。通过前景色降低次要信息权重，避免全页粗体。

`AttendanceLayout` 提供页面 / 行内边距、列表间隔和分组间隔。新共用组件只保留真实重复规则：`AttendancePanel`（有意义的中性边框分组）、`AttendanceListRow`（平坦行与分隔，必要时选中边框）、`StudentIdentityText`（姓名优先、细节次要）。不把每个业务控件包装成独立框架。

## 页面与行为

- 点名保留搜索、筛选、上下文多选、异常入口、手势、长按、状态按钮、撤销及独立草稿。选中状态使用边框与复选框，完成按钮使用中小圆角。
- 材料保留学生头像确认未登记材料的快捷操作及不合格覆盖确认。学生是唯一主体分组，材料行之间使用轻分隔，状态不再控制整行高饱和背景。
- 历史区分类型图标和时间 / 班级元信息。草稿保持可继续处理，完成记录保持安静；查看、编辑与删除语义不变。
- 首页主要操作使用中性模块与小型主色图标；班级切换列表独立显示当前班级，轻点切换、长按管理仍有效，并提供显式管理入口。
- 设置保持已有导航结构，按组显示平坦行。班级项统一显示“跟随全局 / 本班覆写 / 恢复全局”，逐项恢复行为不变。原因排序保留实时跟手、相邻项让位和边缘滚动，仅调整行形状、边界与拖动时的低阴影。

## 验证与继续迭代

`ThemeContrastTest` 检查默认 / 柔和深浅色的正文、辅助文字、状态 tonal fill、主按钮与 Snackbar 对比度；检查黑、白、RGB 和黄色极端 seed 的生成结果、表面稳定性与业务色独立性。主题保存、重载、备份和旧枚举读取有 repository 测试。

`app/src/debug/java/.../DesignPreviews.kt` 提供实际共用学生行、主页、材料页和主题设置的浅色 / 深色预览，以及窄屏大字体学生行。预览数据仅在 debug source set 内，不访问用户 repository，不进入 release。Android Studio 切换到 debug 后可直接打开预览。

自动构建与对比度测试不能替代设备验收。需要在手机上检查：默认/柔和/动态/自定义深浅模式；大字体长姓名；连续点名与 Snackbar；滑动揭示；跨筛选多选；材料头像确认保护；班级覆写恢复；原因拖动与边缘自动滚动。本环境无可用模拟器，尚未做真实设备截图与手势验收。
