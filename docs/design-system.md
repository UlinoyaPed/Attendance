# Attendance 视觉规范

当前规范包含初次统一视觉体系，以及 2026-10-13 基于 `master` 的 `c025a8d` 的视觉与设置调整。产品仍是完全离线、单机使用的班级事务工具；视觉设计以手机上的扫描、连续登记和快速复核为核心。

## NeriPlayer 参考与实际取舍

参考 [NeriPlayer 的 c54884d](https://github.com/cwuom/NeriPlayer/tree/c54884d3600368227f4d6ba86396df5556094199) 的主题及设置源码，重点阅读 `NeriTheme.kt`、`MiuixSettingsScaffold.kt`、`MiuixSettingsControls.kt` 与主题选择控件。采用其有色简介、分组容器、图标底座、清晰的当前值、显式选中反馈和可滚动选择列表这些设计思路，在现有 Compose / Material 3 架构中独立实现。

之前的墨蓝与近乎同色的背景/列表让操作页缺少重点；设置又将结果、折叠和历史选项集中在“界面显示”，当前值不突出，选择对话框也缺少统一规则。现在用蓝紫建立品牌，背景和分组拉开轻微色差，主页点名为主操作、材料为次操作；设置按使用目的整理。保留安静的学生行与历史正文，使业务状态不被彩色背景掩盖。不引入参考项目的 UI 库、播放器功能、调色高级选项或动画系统。

## 审查与改法

| 原实现 | 调整 |
| --- | --- |
| 主题仅提供动态色或 seed，未声明 Shape / Typography | 项目控制的默认配色、四种风格预设、统一形状和排版 |
| 点名整行叠加 24% 状态色，状态头像使用固定色配白图标 | 中性列表、小型 tonal 状态图标、轻分隔线；深浅色独立语义映射 |
| 材料完成项实心主色，学生和材料重复堆叠彩色块 | 学生级边框分组；材料为平坦行，业务绿色表示完成 |
| 草稿与材料历史整张 secondary / tertiary Container | 草稿细主色边框与“继续”；完成记录为安静的信息行 |
| 设置目的地、分组和页面简介重复彩色圆角块 | 页面标题、分组标题、平坦设置行与分隔线 |
| 班级选中态整张染色，当前标记依赖人数开关 | 小面积选中色、细边框、独立当前标记与管理按钮 |
| 页面分别声明 12–24dp 圆角 | 页面使用 MaterialTheme.shapes，圆形头像保留明确用途 |

## 三层颜色

1. **底色层**：浅色背景 `#F4F3FB`、surface `#FFFFFF`；深色背景 `#12121C`、surface `#1B1B27`。普通列表、学生分组与完成历史使用 surface；设置当前值等辅助层按主色的 3.5–11% 与 surface 不透明混合。深色分组不会成为大块亮灰色。outlineVariant 建立需要明确边界的分组，不使用阴影堆出层级。
2. **交互层**：Attendance 浅色主色 `#5559C9`，深色主色 `#C4C1FF`，辅以蓝灰与青绿。主要按钮、选中、进度和继续操作使用主色。首页点名操作允许完整主色背景；页面简介使用低对比的 tonal 渐变，不给每名学生铺满主色。动态和自定义强调色也应用于辅助表面，固定背景、正文与错误角色仍由项目控制。
3. **业务层**：默认到场为绿、迟到为赭黄、请假为蓝、缺勤为红、不参与与未登记为灰。材料完成为绿、不合格为红、未登记为灰。各颜色单独适配深色；用户选择的图标与颜色仍有效，显式选择“主题色”也保留。

业务颜色优先出现在图标和状态文字中。状态 badge / 头像 / 滑动揭示区使用不透明的浅 tonal fill：浅色 6%、深色 10%，与 surface 合成，避免滑动背景穿透前景。滑动触发距离、方向、回弹和回调不变。

## 风格与兼容

- **Attendance**：默认视觉语言。淡蓝紫 / 深墨背景、明快蓝紫交互、清晰紧凑的名单、可识别的设置分组。
- **柔和**：同一业务语义与排版，浅色使用暖白背景，圆角与列表留白更宽松。深色保留清晰的文字对比。
- **系统动态**：Android 12+ 使用壁纸生成的强调色；更旧系统回退到 Attendance。形状、排版、状态和中性表面规则不变。
- **自定义**：一个 `#RRGGBB` 主色及少量快捷色。生成成对的前景/背景强调色，不新增背景、字体或组件圆角设置。

复用现有 `themeSource`（新增 `ATTENDANCE`、`SOFT` 枚举值）和 `themeSeed`。新安装和缺少主题字段的数据默认 Attendance；明确存储的 `SYSTEM`、`CUSTOM` 原样保留。主题仍仅属于全局，不参与班级覆写。旧数据与备份可由新版读取。新预设用可选 `themePreset` 保存，`themeSource` 保留旧版认识的 CUSTOM 主色回退；旧版可恢复业务数据并降级视觉，新版保留完整预设。3c77235 的直接枚举备份也兼容读取，详见 [针对性审查](visual-review.md)。未修改班级、学生、历史快照、草稿或材料数据结构。

## 形状与文字

| token | Attendance | 柔和 | 用途 |
| --- | --- | --- | --- |
| extraSmall | 6dp | 8dp | 紧凑状态标签 |
| small | 12dp | 14dp | 按钮、输入、平坦列表行与小型状态区 |
| medium | 16dp | 18dp | 学生材料分组、图标底座与选择项 |
| large | 20dp | 24dp | 首页操作与设置分组 |
| extraLarge | 28dp | 30dp | 对话框、底部面板 |

`AttendanceTypography` 显式定义全部 Material 文本层级，使用系统 SansSerif。页面标题 24–28sp，模块和学生姓名 16sp Medium，正文 14–16sp，学号、原因与辅助信息 12sp，状态标签 12sp Medium，统计数字 22sp Medium 且使用等宽数字特性。通过前景色降低次要信息权重，避免全页粗体。

`AttendanceLayout` 提供页面 / 行内边距、列表间隔和分组间隔。共用组件只保留真实重复规则：`AttendancePanel`（有意义的边框分组）、`AttendanceListRow`（平坦行与分隔，必要时选中边框）、`StudentIdentityText`（姓名优先、状态独立、细节次要）；`AccentIcon`、`FeatureHeader` 统一入口与简介，`PreferenceChoiceSheet` 统一设置选择。不把每个业务控件包装成独立框架。

## 页面与行为

- 点名保留搜索、筛选、上下文多选、异常入口、手势、长按、状态按钮、撤销及独立草稿。选中的总览筛选在窄屏时自动滚入可见范围；已完整显示时不移动筛选栏。学生选中状态使用边框与复选框，完成按钮使用中小圆角。
- 材料保留学生头像确认未登记材料的快捷操作及不合格覆盖确认。学生是唯一主体分组，材料行之间使用轻分隔，状态不再控制整行高饱和背景。
- 历史区分类型图标和时间 / 班级元信息。草稿保持可继续处理，完成记录保持安静；查看、编辑与删除语义不变。
- 首页使用有色班级简介、主色点名入口、白色/深色材料入口与管理入口，内容可滚动，大字体不截断操作。班级切换列表独立显示当前班级，轻点切换、长按管理仍有效，并提供显式管理入口。
- 设置入口按“日常使用 / 界面与结果 / 数据与备份”分组，一组共用一个表面。搜索仅过滤本地入口与关键词，也可定位常用原因所在页，不产生持久化设置。当前值使用小型 tonal 标签，长值或窄屏大字体上下排列；Switch 使用明确主色选中轨道。
- 未点完确认归入“点名操作”，结果统计和分类折叠归入“结果排列”，历史统计归入“历史记录”。分类关闭时隐藏仅用于分类的选项并说明如何开启，原设置值不丢失。
- 状态、原因、手势、图标等选择统一用可滚动 Bottom Sheet，打开时定位到当前选择附近，点击即沿用原保存回调。四种主题以实际色板卡片预览；仍只在自定义模式显示主色输入。
- 班级项统一显示“跟随全局 / 本班设置 / 恢复全局”，恢复入口保持独立触摸目标，整班恢复需确认。主题、头像和备份不会出现在班级覆写中。原因排序保留实时跟手、相邻项让位和边缘滚动。

## 验证与继续迭代

`ThemeContrastTest` 检查默认 / 柔和深浅色的正文、辅助文字、状态 tonal fill、主按钮与 Snackbar 对比度；检查极端 seed、渐变两端、选中背景与业务色独立性。主题保存、重载、备份和旧枚举读取有 repository 测试。

`VisualInteractionTest` 使用 Robolectric API 35 native graphics 与真实 Compose 组件，在 320dp、1.5 倍字体下渲染 PNG；验证主页入口可点击和滚动、班级恢复不会触发 Switch、100 项原因列表能打开当前值并选择末项、材料头像默认不覆盖不合格、相同自定义图标/颜色时仍显示状态文字。截图是测试数据，不访问用户存储，写入 `app/build/reports/ui/`；CI 上传 `Attendance-ui-checks` artifact。Robolectric 和测试宿主均只在测试 / debug 中使用，不进入 release APK。

`app/src/debug/java/.../DesignPreviews.kt` 提供实际共用学生行、主页、材料页和主题设置的浅色 / 深色预览，以及窄屏大字体学生行。预览数据仅在 debug source set 内，不访问用户 repository，不进入 release。Android Studio 切换到 debug 后可直接打开预览。

本地 Android 渲染与对比度测试不能替代设备验收。仍需在手机上检查：系统壁纸动态色、实际键盘、连续点名与 Snackbar、滑动揭示与回弹、跨筛选多选、原因拖动和边缘滚动。本环境无可用模拟器，尚未完成真机截图与连续手势验收。
